No – there is no published, universal two‑digit superscript convention for per‑head weight matrices in Transformer diagrams.  

The standard notation from the original “Attention Is All You Need” paper (section 3.2.2) uses a **subscript for the head index and a superscript for the role**, e.g.:

\[
W_i^{Q},\; W_i^{K},\; W_i^{V}
\]

(where \(i\) = head number).  

Two‑digit superscripts like \(W^{01}, W^{11}, W^{12}, W^{21}\) appear only in specific lecture notes or code examples as ad‑hoc labels (sometimes meaning “layer, head” or just arbitrary enumeration) and are **not** a widely adopted convention.
