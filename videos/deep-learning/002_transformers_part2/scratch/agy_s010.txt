**2. “Attention Is All You Need” (Vaswani et al., 2017), § 3.2.2**  
The query projection matrix is denoted $W^{Q}$ (or $W_i^{Q}$ per head) and is a learned projection of the input embeddings from $d_{\text{model}}$ to $d_k$.  
> “The weight matrix $W_i^{Q}$ (often denoted as $W^{Q}$ in individual heads) is a learned parameter matrix used to project the input embeddings into the **Query** space for each attention head”【1†L1-L4】  
> “For each head $i$, the projections are defined as: $$Q_i = XW_i^{Q},\quad K_i = XW_i^{K},\quad V_i = XW_i^{V}$$ where $W_i^{Q}\in\mathbb{R}^{d_{\text{model}}\times d_k}$”【1†L5-L9】  
Source: https://arxiv.org/abs/1706.03762 (section 3.2.2)
